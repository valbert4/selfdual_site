Extremal 72

Extremal 72 is a community effort to decide whether a binary Type II [72,36,16] code exists.

The project has two possible endings:

  • Find the code, producing a remarkable extremal self-dual object connected to designs, lattices, quantum CSS codes, and code/CFT constructions.
  • Rule it out, settling a problem posed by Sloane in 1973.
