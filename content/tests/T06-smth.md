# T06 - Toggle-Stabilizer Smith Congruence

Status: `proof-grade kills`

## Summary

The translation group generated by two disjoint anchors and the all-ones word
forces certain split categories to have counts divisible by powers of two. This
test rejects rows that cannot meet those exact congruences.

## What It Tests

- Object: the toggle-stabilizer divisibility of the `16|16|40` split categories.
- Input: the row `(k,a,b)` and the integer congruence system.
- Necessary condition: the split counts satisfy the forced
  toggle-stabilizer congruences (a genuine integer-lattice condition, stronger
  than plain integrality).
- Output: rows failing the congruences.

## Result

- Kills: `16` — the even-`a` rows at `k=6`.
- Status: proof-grade. At `k=6` the system is infeasible exactly when `a` is
  even; the binding layer is toggle-stabilizer divisibility, not integrality
  alone.

## Verification

- Certificate type: Smith normal form over the integers (cross-checked by an
  independent GLPK-MILP witness finder).
- Reproduce: download the reproduction bundle below and run it.
