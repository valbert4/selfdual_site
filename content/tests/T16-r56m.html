T16 - Length-56 Residual Biweight Global Mixture

Status: saturates

Public Summary

This test couples the length-40 menu to the genus-2 biweight of the [56,21] residual through a global mixture. It is feasible for every surviving row — one of the clearest reasons the problem remains hard.

What It Tests

  • Object: the residual [56,21] biweight, coupled to the menu via a global aggregate mixture.
  • Input: the row (k,a,b) and the residual biweight family.
  • Necessary condition: each surviving row appears in some nonnegative aggregate mixture of residual biweights.
  • Output: rows that cannot appear in any mixture (none, here).

Result

  • Kills: 0.
  • Status: saturates. The residual biweight is itself only a family — exactly 9-dimensional standalone, 5-dimensional under the length-72 anchored coupling — and that remaining freedom absorbs the global mixture demand.
