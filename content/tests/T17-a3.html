T17 - A3 Constant-Weight SDP

Status: validation standard documented; no public elimination

Public Summary

A Schrijver/A3 three-point SDP bound on the weight-16 words at length 40. This page states the exact conditions an A3-style bound must meet before it is allowed to change the public menu count.

What It Tests

  • Object: the weight-16 words of E as a constant-weight code, bounded by the three-point (A3 / Schrijver) SDP hierarchy.
  • Input: the row (k,a,b) and the A3 constraint system.
  • Necessary condition: the required count a is at most the valid A3 bound.
  • Output: rows exceeding a proof-grade A3 bound.

Result

  • Kills: 0 (no public elimination).
  • Status: validation target. Only the R-only A3 constraints are valid; the bound must be produced from an exact, replayable certificate before any row is cut.

Verification

Requirements for an A3 elimination to count publicly:

  • the constraint system is stated with no hidden projection blocks;

  • all coefficients are exact, or reconstructed exactly from modular data, before any LP/SDP solve;

  • the solver certificate is independently replayable;

  • known small codes and saturated rows pass the same validator;

  • each killed row carries a row-level dual certificate.

  • Certificate type: exact SDP dual certificate (required, not yet produced).

Reproduction bundle

Download T17-a3-repro.tar.gz — a 🔴 bundle. This test is open / validation-only: an A3 bound needs an exact, replayable dual certificate before it counts. The archive ships a spec and the source path, not a one-click run. Checksums: manifest.json.

How To Help

Produce a proof-grade R-only A3 bound with an exact, replayable dual certificate, validated first on a known code, then on the surviving high-a rows.
