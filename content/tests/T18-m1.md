# T18 - Mode-1 Per-Coset Upward-Glue Obstruction

Status: `validation standard documented; no public elimination`

## Public Summary

This test strengthens aggregate gluing to genuine per-coset tilings of the
upward `40 -> 56` step. This page states the stringency a per-coset obstruction
must meet before it can eliminate a row.

## What It Tests

- Object: the per-coset tiling of the upward-glue profiles (Mode-1).
- Input: the row `(k,a,b)`, the image counts, and the per-coset profile pool.
- Necessary condition: a valid per-coset tiling exists that realizes the row.
- Output: rows with no valid tiling (subject to the requirements below).

## Result

- Kills: `0` (no public elimination).
- Status: validation target. A Mode-1 kill is counted only when the image counts
  are exact and no constructive witness exists for the same row.

## Verification

Requirements for a Mode-1 elimination to count publicly:

- image counts are produced by an exact, independently checked routine;
- every coset table uses the same row-level normalization;
- local infeasibility survives witness-preserving consistency checks;
- any constructive witness for the row is ruled out under the exact hypothesis;
- the certificate names exactly which row and which local object fails.

- Certificate type: exact integer Farkas certificate per tiling (required).
