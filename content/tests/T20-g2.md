# T20 - Coupled Genus-2 Biweight Feasibility

Status: `proof-grade kill`

## Summary

This test checks whether a length-40 row admits a nonnegative point in the exact
genus-2 (biweight) family, coupled to its dual-closure constraints. One row has
no such point.

## What It Tests

- Object: the per-row genus-2 biweight of `E`, with dual-closure ties.
- Input: the row `(k,a,b)` and the exact coupled biweight system.
- Necessary condition: a nonnegative point exists in the coupled biweight family.
- Output: rows with an empty coupled family.

## Result

- Kills: `1` — `(9,239,32)`. Nearby rows remain feasible, so the cut is sharp.
- Status: proof-grade (exact biweight nonnegativity infeasibility).
