T21 - Row-Aware A3 Feasibility

Status: saturates

Summary

This test ties row-specific genus-2 "boxes" to anchored constant-weight (A3) bounds, run as a per-row feasibility problem. The available two-point bounds are too weak to cut any current row.

What It Tests

  • Object: the intersection pattern of a row's weight-16 words, with genus-2 ties.
  • Input: the row (k,a,b) and the anchored two-point Delsarte bounds.
  • Necessary condition: the genus-2-tied two-point bounds admit the row.
  • Output: rows exceeding the anchored bounds (none, here).

Result

  • Kills: 0.
  • Status: saturates. The exact anchored two-point (product-Johnson) bounds are far above the per-row minima, so nothing is cut. A genuine three-point strengthening would be needed to bite.

Verification

  • Certificate type: exact-rational (QQ / PPL) two-point feasibility.
  • Reproduce: download the reproduction bundle below and run it.
