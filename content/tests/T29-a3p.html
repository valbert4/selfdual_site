T29 - Anchored 3-Point SDP

Status: linear layer done; PSD critical/open

Public Summary

The single-anchor anchored three-point SDP on the length-72 minimum-word structure, coupled to the menu. The deepest test attempted so far; its PSD layer sits exactly on a feasibility boundary and has not produced a proof-grade kill.

What It Tests

  • Object: the anchored three-point configuration of length-72 minimum words, coupled to the menu mixture.
  • Input: the menu, the anchored linear gate, and the moment-matrix (PSD) blocks.
  • Necessary condition: the anchored SDP is feasible (linear gate) and the moment matrix is positive semidefinite.
  • Output: rows or mixtures the SDP excludes.

Result

  • Kills: 0.
  • Status: the linear layer is proof-grade and exhausted (exact glpsol, all mixtures feasible — it does not pin the triweight beyond V-positivity). The PSD layer is open: it sits at the double-precision floor (MOSEK boundary margin ≈ 0, sign-undeterminable; SDP solvers either unresolved or out of memory).

Verification

  • Certificate type: linear layer — exact glpsol feasibility (done). PSD layer — an exact / high-precision SDP certificate is required and not yet obtained.
  • Reproduce: download the reproduction bundle below and run it. exact SDP (e.g. CSDP) or a symmetry block-diagonalization.

Reproduction bundle

Download T29-a3p-repro.tar.gz — a 🔴 bundle. This test is open / validation-only: anchored 3-pt SDP: linear layer 0 kills (exact); PSD layer open at the boundary. The archive ships a spec and the source path, not a one-click run. Checksums: manifest.json.

How To Help

Resolve the PSD boundary: block-diagonalize by the anchor symmetry to shrink the SDP, or run an exact/high-precision solver that can determine the sign at the margin.
