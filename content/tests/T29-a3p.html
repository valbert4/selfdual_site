T29 - Anchored 3-Point SDP

Status: linear layer done; PSD critical/open

Summary

The single-anchor anchored three-point SDP on the length-72 minimum-word structure, coupled to the menu. The deepest test attempted so far; its PSD layer sits exactly on a feasibility boundary and has not produced a proof-grade kill.

What It Tests

  • Object: the anchored three-point configuration of length-72 minimum words, coupled to the menu mixture.
  • Input: the menu, the anchored linear gate, and the moment-matrix (PSD) blocks.
  • Necessary condition: the anchored SDP is feasible (linear gate) and the moment matrix is positive semidefinite.
  • Output: rows or mixtures the SDP excludes.

Result

  • Kills: 0.
  • Status: the linear layer is proof-grade and exhausted (exact glpsol, all mixtures feasible — it does not pin the triweight beyond V-positivity). The PSD layer is open: it sits at the double-precision floor (MOSEK boundary margin ≈ 0, sign-undeterminable; SDP solvers either unresolved or out of memory).

Verification

  • Certificate type: linear layer — exact glpsol feasibility (done). PSD layer — an exact / high-precision SDP certificate is required and not yet obtained.
  • Reproduce: download the reproduction bundle below and run it. exact SDP (e.g. CSDP) or a symmetry block-diagonalization.

Moment-matrix assembly (pair_type → block/row/col)

The moment matrix M is block diagonal, one block per anchor layer a = |U ∩ B| ∈ {0,2,4,6,8}. Block a is indexed by exactly the anchored ordered pair types whose first coordinate equals a, in increasing global pair-type index order (anchored_orbits.pair_types(), which is sorted(...)); the block sizes are 25 / 57 / 75 / 83 / 85 (Σ = 325). Entry (i,j) of block a is the exact linear form

M_a[i,j] = [i==j]·p_{P(i)}  +  (|Y_B|−2)·Σ_o c^a_{ij,o}·z_o,     |Y_B|−2 = 249846,

so the triweight_pin.json key pair_type = τ sits at exactly one place in M: the diagonal of block τ[0], at row = col = its position within that block.

  • The col field in triweight_pin.json is not a matrix index — it is the genus-3 enumerator's AGL(3,2) orbit column (into the 6×4228 exact-V matrix N), used only to pin p_τ = (N0 + a₁N1 + … + a₅N5) / (64·A16), A16 = 249849. Example: (0,0,0,0) has col=82 but sits at block 0, row/col 0, with N=[0,64,0,0,0,0], i.e. p_(0,0,0,0) = a₁/A16.
  • The five-parameter pinning acts on the diagonal (pair) part only. The z block (every off-diagonal entry, and the triple part of each diagonal) is the large free block; reducing it to the same five coordinates is the separate step done with triweight_q_constraint.json and the genus-3 bases. M is affine in (p, z), not 5-parameter until that reduction is applied.

The full construction is the project's own MIT code (anchored_orbits.py, psd_blocks.py), shipped verbatim in the bundle below along with a driver that emits the complete pair_type → (block,row,col) map and, with --full, the entire symbolic M(p,z). Precomputed map: t29_moment_matrix_map.json.

Reproduction bundle

Download T29-a3p-repro.tar.gz — a 🟢 exact-replayable bundle for the assembly (pure Python, no solver; sh run.sh rebuilds the 5 blocks and certifies the map in ~30–60 s). The final PSD-margin verdict at the boundary remains open. Checksums: manifest.json.

How To Help

Resolve the PSD boundary: block-diagonalize by the anchor symmetry to shrink the SDP, or run an exact/high-precision solver that can determine the sign at the margin. The moment-matrix assembly above (and its bundle) gives the exact M(p,z) to feed such a solver.
