The single-anchor anchored three-point SDP on the length-72 minimum-word

## Moment-matrix assembly (`pair_type` → block/row/col)

The moment matrix `M` is **block diagonal**, one block per anchor layer
`a = |U ∩ B| ∈ {0,2,4,6,8}`. Block `a` is indexed by exactly the anchored ordered
pair types whose first coordinate equals `a`, in increasing global pair-type index
order (`anchored_orbits.pair_types()`, which is `sorted(...)`); the block sizes are
`25 / 57 / 75 / 83 / 85` (Σ = 325). Entry `(i,j)` of block `a` is the exact linear
form

```
M_a[i,j] = [i==j]·p_{P(i)}  +  (|Y_B|−2)·Σ_o c^a_{ij,o}·z_o,     |Y_B|−2 = 249846,
```

so the `triweight_pin.json` key `pair_type = τ` sits at exactly one place in `M`:
the **diagonal of block `τ[0]`**, at `row = col = ` its position within that block.

- The `col` field in `triweight_pin.json` is **not** a matrix index — it is the
  genus-3 enumerator's AGL(3,2) orbit column (into the `6×4228` exact-V matrix
  `N`), used only to pin `p_τ = (N0 + a₁N1 + … + a₅N5) / (64·A16)`, `A16 = 249849`.
  Example: `(0,0,0,0)` has `col=82` but sits at block 0, row/col 0, with
  `N=[0,64,0,0,0,0]`, i.e. `p_(0,0,0,0) = a₁/A16`.
- The five-parameter pinning acts on the diagonal (pair) part only. The `z` block
  (every off-diagonal entry, and the triple part of each diagonal) is the large
  free block; reducing it to the same five coordinates is the separate step done
  with [`triweight_q_constraint.json`](/downloads/enumerators/triweight_q_constraint.json)
  and the genus-3 bases. `M` is affine in `(p, z)`, not 5-parameter until that
  reduction is applied.

The full construction is the project's own MIT code (`anchored_orbits.py`,
`psd_blocks.py`), shipped verbatim in the bundle below along with a driver that
emits the complete `pair_type → (block,row,col)` map and, with `--full`, the entire
symbolic `M(p,z)`. Precomputed map:
[`t29_moment_matrix_map.json`](/downloads/enumerators/t29_moment_matrix_map.json).
