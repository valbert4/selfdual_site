# T33 - Forced Sibling D32 Classification

Status: `saturates; structural result`

## Summary

Fix two disjoint weight-16 codewords `B, B'` of the putative `[72,36,16]` code;
their supports span 32 coordinates. Shortening the code on those 32 coordinates
gives a sibling code `D32`, the exact complement of the length-40 menu residual
`E`. This test classifies `D32` completely and shows it is a fixed, rigid object.

## What It Tests

- Object: the sibling code `D32 = { c|_T32 : c ∈ C, supp(c) ⊆ T32 }` on
  `T32 = supp(B) ∪ supp(B')`, complementary to the length-40 residual `E`.
- Input: the Janusz dimension law `k = s + 4`, double-evenness, and minimum
  distance `16`.
- Necessary condition: `D32` is a doubly-even self-orthogonal `[32, k-4, 16]`
  code containing `1_32` whose nonzero non-`1` words all have weight `16`.
- Output: the unique `D32` per `k`, its automorphism group, and the three-block
  `l = 0` column it pins.

## Result

- Kills: `0` — saturates. The count-level content (the `l = 0` column
  `Z[8,8,0] = 2^(k-4) - 4`) is already imposed by the three-block screens T5 and
  T24, and that system saturates.
- Structure: `D32` is forced to be the unique (per `k`) `[32, k-4]` subcode of
  `RM(1,5)` containing `1_32`, with `W_D32 = 1 + (2^(k-4) - 2) y^16 + y^32` and
  `|Aut| = (2^(6-s)!)^(2^(s-1)) · |AGL(s-1,2)|`, `s = k-4`.
- Status: saturates at the enumerator level; its value is a proof-grade
  derivation of the supported-dimension input the three-block screen asserts (it
  follows from the Janusz dimension law, not an ansatz) plus a rigid heavy object
  that seeds the gluing routes.
