# Prototype Site

Static local prototype for the selective public site.

Run from the `website` directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8000/prototype/
```

This preview is local-only. A later GitHub Pages deployment from a normal
non-Enterprise account should be treated as public.
